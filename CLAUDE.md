# ABSOLUTI historical club

Сайт исторического клуба. Next.js 15 (App Router, TypeScript), админка с паролем + TOTP 2FA (iron-session, otplib). Язык интерфейса и контента: русский.

Запуск: `npm run dev` → http://localhost:3000
Проверки: `npx tsc --noEmit`, `npm run lint`, `npm run build`, `npx playwright test`

Публичные маршруты: `/`, `/about`, `/events`, `/news`, `/photos`.
Админка: `/admin/login`, `/admin/dashboard`, `/admin/posts`, `/admin/events`.
Контент: `/content` (MDX/JSON).

## Как работать

- План: `PLAN.md`. Статус: `docs/PROGRESS.md`. Агенты и скиллы: `docs/TOOLS.md`. Детали проекта: `AGENTS.md` (если файл есть, прочитай его).
- Фаза запускается командой `/phase N`, полная проверка — `/checks`.
- Делай маленькие шаги и проверяй каждый. «Готово» пиши только после того, как проверки прошли.
- Перед любой работой с интерфейсом загрузи скилл `frontend-design`.
- Секреты не печатай и не коммить. Не выдумывай факты о клубе: бери тексты из `/content` или ставь явные заглушки и перечисляй их в отчёте.
- Если ответ на вопрос меняет результат, задай один короткий вопрос. Иначе выбери разумный вариант и напиши, что выбрал.
