# Arts Club Reference Notes

Extracted from https://www.theartsclub.co.uk via Playwright (1440, 1024, 375px).

## Шапка (Header) — 1440px
- **Высота:** 120px
- **Логотип + Название:** Центрированы, логотип — эмблема в круге, название «THE ARTS CLUB» капителью
- **Шрифт названия:** Cormorant Garamond (или подобный с засечками), uppercase
- **Letter-spacing:** ~0.3em (очень широкий)
- **Цвет:** #FFFFFF (белый) или #1A1A1A (темный на фото)
- **Информационная строка (слева):** «Open daily 10:00 - 18:00», цвет #b07a5a (теплый коричневый)
- **Меню (справа):** пунктки с расстоянием ~16px, шрифт Inter/Onest, размер 0.875rem, цвет #FFFFFF
- **Hover:** фон подсветки снизу, переход 0.2s
- **Активный пункт:** подчвечивание или цвет изменение до #b07a5a
- **Меню-мобилка:** бургер в углу, slide-in панель

## Hero — 1440px
- **Фото:** на всю ширину экрана, сразу под шапкой
- **Высота:** ~500px (заполняет экран с учетом шапки)
- **Пропорции:** 16:9 или 4:3, объект покрывает большую часть ширины
- **Подпись/Заголовок:** поверх фото, полупрозрачный фон rgba(0,0,0,0.4)
- **Заголовок:** крупный, Cormorant Garamond, ~4rem, white
- **Подзаголовок/подпись:** меньше, Onest/Inter, trackingwide, #E8E8F0

## Меню — 1440px
- **Шрифт:** Inter или Onest, sans-serif
- **Размер:** 0.875rem (14px)
- **Цвет:** #FFFFFF на белом фоне
- **Зазоры между пунктами:** 16-20px (letter-spacing: 0.05em)
- **Hover:** фон rgba(255,255,255,0.1) под текстом, цвет текста #b07a5a
- **Активный пункт:** underline снизу 2px solid #b07a5a или смена цвета на #b07a5a
- **Мегаменю:** при ховере одного пункта выпадает колонка с ссылками,左右 padding 24px,间隔 12px между ссылками

## Карточки — 1440px
- **Пропорции:** 5:4 (ширина:высота)
- **Фото:** покрывает всю ширину карточки, height: calc(width * 1.25), объект cover
- **Подпись:** под фото, шрифт Inter, 0.875rem, цвет #6B6B6B, tracking wider
- **Кнопка «Read more»:** справа снизу, padding 8px 16px, фон прозрачный, border 1px solid #b07a5a, цвет текста #b07a5a, transition 0.2s
- **Hover:** фон карточки #F5F0E8 (очень светлый), transform translateY(-4px)

## Цветовая палитра
- **Фон:** #FFFFFF (белый)
- **Текст:** #1A1A1A (чёрный) или #2D2D2D (очень тёмныйgray)
- **Один акцент:** #b07a5a (теплый коричневый)
- **Вторичный акцент (строка открыт):** #b07a5a
- **Текст-muted:** #6B6B6B, #737373

## Шрифты (Google Fonts замена Adobe Typekit)
- **Serif для названия и заголовков:** `Cormorant Garamond` с `subsets: ['latin', 'cyrillic']`
- **Sans для меню и текста:** `Inter` с `subsets: ['latin', 'cyrillic']`
- **Проверка кириллицы:** оба шрифта поддерживают кириллицу, но Cormorant Garamond имеет broader glyph set для русских текстов
- **Letter-spacing:** 
  - Название: uppercase, tracking 0.2-0.3em
  - Подпись LONDON: uppercase, tracking 0.5em (ещё больше)
  - Меню: tracking-normal или легкий 0.02em
  - Карточки: tracking wider

## Общие принципы
- **Белый фон**, один акцент #b07a5a
- **Много воздуха** (large margins, generous padding)
- **Никаких градиентов, теней, скруглений «из коробки»** — скругления только по necesidad (вертинги имеет border-radius 0)
- **Анимации сдержанные:** transition 0.2s на цвет/фон, hover-effects
- **prefers-reduced-motion:** все анимации отключаются, мгновенное изменение состояний
